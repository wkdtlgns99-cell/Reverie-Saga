## Contract

Use the current `--world-knowledge` working world and its active branch. The separate **Reverie → 보급 의뢰 플레이** editor panel opens or refreshes a preview. An absent default working file can start a new registered knowledge world through the existing owner. An existing owner produces an explicit lock diagnostic. Each short-lived Python request takes the existing single-writer lock for its lifetime. The Unity panel offers only the current authored supply action, or a one-second wait at the quest city before the incident opens. Show the authored line, recipient, consequences, deadline and action time before an explicit confirmation. After committing, show the saved status, cargo and money. If the quest is already complete, expired or elsewhere, show committed state and no actionable offer. If committed speech still has an unfinished segment, direct the player to finish it in Python before this bounded panel can act.

Use `python -m app.world_supply_bridge [--working PATH] [--confirm TOKEN]`. Preview sends no turn. A confirmation is exactly 64 lowercase hexadecimal characters, minted by the bridge from its protocol version, resolved working path, committed branch and revision, last committed core hash if present, and offered action identity and terms. Each process reopens the owner and recomputes the offer before submission. A stale token returns `WORLD_SUPPLY_STALE` with current preview and no turn. An unavailable or locked save fails explicitly with no JSON. If the response is lost after COMMIT, a same-token retry shows current state without repeating the action. A precommit failure permits resubmission from the same committed state using the existing registered command and identity. A confirm request for a missing save never initializes it. There is one request per child, with a bounded stdout/stderr and a deadline. No provider calls.

The stdout document uses format `reverie-world-supply/v1` and carries integer tick, revision, cargo, cargo required and gold, Korean location, supply status, notice and optional error code. Optional offer has label, dialogue line, terms and confirmation token. Empty/no offer is null and `has_offer` is false so Unity can distinguish it from its default nested object. The panel disables action while a request is pending. Canceling the confirmation dialog sends nothing. A stale preview displays the latest state and requires a fresh explicit confirmation. Unsupported or malformed input cannot dispatch an arbitrary command. Reuse existing `WorldWorker`, `SupplyOffer`, `authored_supply_line`, and process ownership rules. Python owns all effects. For a fresh world the normal path is wait → accept → collect → collect → deliver, ending at tick/revision 5 with zero cargo and 5 gold.
