Contracts violated:
- CORE-05 export step 6: a failure before the final replace returns SAVE_EXPORT_FAILED.
- CLIENT-002: worker errors project as an error view, and accepted work drains before owner close.
Trigger: any sqlite3.Error raised while backing up the working file for a slot save, for example disk full. sqlite3.Error is not an OSError or RuntimeError, and SqliteCommitStore._backup_reserved (sqlite_store.py:497) and _connect do not wrap it. SqliteSlots.export therefore lets it through raw.
Actual behavior:
1. Reproduction A. With a real ClientWorker, I injected OperationalError("database or disk is full") when opening the export temp. The save Future raised the raw OperationalError instead of returning a ClientUpdate. Authoritative state was fine: the worker thread stayed alive and the next down committed.
2. Reproduction B. I called the real PlayWindow._poll with that failed Future. self._pending.result() re-raises, and the code that re-arms root.after is never reached. _pending stays set, so busy is true forever, buttons stay disabled, and the poll loop is dead.
3. Reproduction B, close path. With close() already called, _poll still raised. root.destroy() was never called and closed stayed false. The finally: worker.join() in main is unreachable until the mainloop exits, so the process has to be killed.
Verification limit: this used a stub tkinter to call the real method, not a real Tk window. Tk reports an exception inside an after callback and does not reschedule it, which is what the stub showed.
Expected: a SAVE_EXPORT_FAILED error update, buttons re-enabled, and the window closable.
Bounded repair:
1. In the adapters, map sqlite3.Error to SAVE_EXPORT_FAILED / SAVE_LOAD_FAILED. Add it explicitly to the except tuples in export and stage_load, and wrap the backup call in _backup_reserved.
2. In _poll, check future.exception() before .result() and render a CLIENT_ERROR update. That needs no except Exception, so it avoids the BLE001 lint question.
3. Re-arm root.after in a finally.
4. If you also want a catch-all in ClientWorker._run, that touches the lint policy and needs explicit director authority.
